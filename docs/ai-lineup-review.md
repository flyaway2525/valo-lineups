# AI による定点の確認・登録の手順（プロンプト）

AI（Claude）が X・YouTube・Discord などの動画や画像から定点を登録したり、
「要確認」の定点を見直したりするときの決まりごと。作業を始める前にこのファイルを読むこと。

ゴールは、**スマホで定点を開いた人が、画像と文字だけでその場で再現できること**。
「どのあたりか」はマップのピンで分かるので、画像と文字では
「何を目印に、どこに立ち、何をどこに合わせて投げるか」を伝える。

---

## 1. 立ち位置（画像 1 枚目・メモ）

大まかな位置はマップのピン（`from`）で分かる。画像とメモでは **何を目標に立つか** を示す。

- 立ち方を言葉にする。例：
  - 「A メイン出口の右の角に体を張り付ける」
  - 「真下を向いて、床のタイルの十字にクロスヘアを合わせる」
  - 「箱の左端と壁の継ぎ目が重なる位置に立つ」
- 画像は、その目標（角・タイル・箱など）がはっきり写っているコマを選ぶ。
  走っている途中や画面が揺れているコマは使わない。
- 目標の部分を **赤丸（または赤枠）で囲む**。
- 「どこに立っても良い」スキル（ブリムのスカイスモーク、オーメンのダークカヴァーなど）は
  `anyFrom: true`（立ち位置なし）にして、この枠は「置く画面」に使う。

## 2. 照準（画像 2 枚目・メモ）

**何を、どこに合わせるか** を明記する。

- 例：
  - 「ショックダーツのアイコンの上端を、建物の屋根の右の角に重ねる」
  - 「クロスヘアを看板の左上の角に合わせる」
  - 「ピンを刺して 25m 表示のところに合わせる」
- 投げ方も書く：通常／ジャンプ投げ／走り投げ／しゃがみ投げ／右クリック、
  ソーヴァはチャージ量とバウンド数（例：1 バウンド・フルチャージ）。
  あてはまるものは `throwType` にも入れる。
- 画像は、合わせる目印とクロスヘア（またはスキルの UI）が両方写っている、
  **投げる直前で止まっているコマ** を選ぶ。合わせる位置を **赤丸で囲む**。
- 投稿者の動画に赤丸や矢印などの印が入っていれば、そのコマを優先して使う。

## 3. 着弾（画像 3 枚目）

- **着弾の様子が引き気味のカメラで写っている** コマを選ぶ。
  リコンのスキャン範囲、モロトフの広がり、スモークの位置などが周りと一緒に分かるもの。
- 俯瞰のリプレイや観戦視点があればそれを優先する。
  一人称でスキル以外が分からないアップのコマは避ける。
- スモークなど立ち位置なしの定点では、ここは「外から見た様子」（置いたスモークを周りから見た画像）。

## 4. 良い画像がないとき

- **人が見て分かりやすい画像がなければ、無理に付けない**（その枠は空のままで良い）。
- 分かりにくい画像を付けるより、メモに文字で書くほうがよい。
- 動画のリンク（`videoUrl`）は必ず付ける。

## 5. メモ（`notes`）の書き方

次の順で短く書く。分からない項目は書かない（推測で埋めない）。

```
立ち位置：A メイン出口の右の角に張り付く
照準：アイコンの上端を屋根の右の角に重ねる
投げ方：ジャンプ投げ（1 バウンド・フルチャージ）
効果：A サイトのデフォルト設置位置をスキャン
```

## 6. 状態（`status`）の付け方

| 状態 | いつ |
|---|---|
| `ai`（AI確認済み） | 動画で **マップ・攻守・スキル・サイトが合っていること** と、立ち位置・照準・着弾が上の基準で説明できたことを確認した |
| `check`（要確認） | 位置や合わせ方が動画から読み取れない、複数の定点をまとめた動画で 1 件に絞れない、古い投稿（マップ変更で使えない可能性）など |
| `ok`（有効） | **AI は付けない**。人が実際にゲームで試して使えたときだけ人が付ける |

`statusNote` には、何を見て判断したか・何を直したかを書く
（例：「動画のコールアウトからマップはサンセットではなくバインドだったので修正」）。
`statusByName` は `AI確認`。

## 7. 確認するときに気をつけること

- 投稿文のマップ名・サイト名をうのみにしない。動画のミニマップ・コールアウト表示で確かめる
  （実際に、ヘイヴンと書かれていてアセントだった、A と書かれていて C だった、などが何件もあった）。
- 攻守は「どちら側から投げているか」で決める（サイトの中から外へ投げる＝守り、など）。
- 人が編集した定点（`updatedAt` ≠ `createdAt`）は、位置やタイトルを上書きしない。状態とメモだけ更新する。
- 1 本の動画に複数の定点があるときは、それがメモで分かるように書く。

## 道具（参考）

- X の動画：`cdn.syndication.twimg.com/tweet-result?id=...&token=4` で mp4 の URL を取得。
  ダウンロードには `User-Agent`（ブラウザ）と `Referer: https://x.com/` が必要。
- コマの確認：ローカルの capture ページ（`$TEMP/vcap/index.html`）で、
  コンタクトシート（8 コマ＋左上のミニマップ拡大）を作って見る。
  使うコマを決めたら、その時刻で切り出す（長辺 1280px・WebP・700KB 以下）。
- 赤丸：切り出しのときに canvas で円を描いてから保存する
  （位置は 0〜1 の比率で指定。`ctx.strokeStyle = '#ff2b2b'; ctx.lineWidth = 6;`）。
- 登録・更新は Firestore REST（`firebase projects:list` でトークンを更新してから）。
